# 🧮 Calculadora Simples em Python

## 📝 Sobre o Projeto
Este é um projeto de uma calculadora interativa via terminal, desenvolvida para realizar as quatro operações matemáticas básicas. 

O principal objetivo deste repositório é aplicar e fixar conhecimentos fundamentais da linguagem Python. É um projeto simples e leve, construído como um ponto de partida para alimentar meu portfólio e desenvolver de forma prática minhas habilidades em lógica de programação.

## ⚙️ Funcionalidades
A calculadora possui um menu interativo que permite ao usuário escolher entre:
*   ➕ **Somar**
*   ➖ **Subtrair**
*   ✖️ **Multiplicar**
*   ➗ **Dividir**
*   ❌ **Encerrar o programa**

## 🛠️ Conceitos e Tecnologias Aplicadas
Durante o desenvolvimento deste código, coloquei em prática conceitos essenciais do Python:
*   **Modularização com Funções (`def`):** Separação da lógica matemática em um arquivo dedicado (`funcoes.py`), mantendo o código limpo e organizado.
*   **Tratamento de Exceções (`try` / `except`):** Prevenção de "quebras" do programa caso o usuário digite letras em vez de números ou tente realizar uma divisão por zero.
*   **Estruturas Condicionais (`if` / `elif` / `else`):** Controle do fluxo de navegação do menu interativo.
*   **Laços de Repetição (`while`):** Manutenção do programa em execução contínua até que o usuário decida sair.
